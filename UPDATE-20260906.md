# StireOS update — 2026-09-06

This signed update adds the first application-window foundation:

- integrated title and window controls for minimize, gapped maximize,
  true fullscreen and close;
- draggable rounded application windows with restrained compositor motion;
- equal 12 px outer spacing in the maximized desktop layout;
- true fullscreen that hides the taskbar and right system capsule;
- running-application entries on the taskbar;
- the native `Bilgisayarım` launcher backed by Thunar and GVfs;
- a managed Hyprland base configuration so installed systems receive future
  compositor fixes, with `~/.config/hypr/stire-overrides.lua` reserved for
  personal additions;
- resilient shell restarts that recover the active Wayland and Hyprland IPC
  environment.

Validated in the installed 1920×955 VM through clean package installation,
two full reboots, normal/maximized/fullscreen transitions, package integrity
checks, Hyprland config validation and idle sampling. The shell and compositor
both measured 0.0% CPU in the final one-second idle sample.
