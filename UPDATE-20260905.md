# StireOS update — 2026-09-05

- `stire-config 0.1.0-5`: migrate installed ArchISO temporary keyring units
  to the persistent, populated keyring; remove the associated boot-time clock
  wait. NTP synchronization itself remains enabled.
- Enable Plymouth through GRUB and initramfs; retain its final frame during
  compositor handoff. Hyprland logs go to the session log, not the boot TTY.
  Recovery remains available on compositor failure. Firmware and the dual-boot
  selection menu are outside the Linux splash's coverage.
- Limit automatic compositor startup to a real tty1 login. Add StireOS Terminal
  (Foot with a clean interactive Bash shell) and a pinned taskbar button.
- `stire-shell 0.1.0-4`: enable native Wi-Fi scanning while panels are open,
  with multi-monitor reference counting and shutdown when no panel needs it.
  Correct unsupported Qt.rgb calls without changing the intended color values.

## Validation and limits

Updated an installed EFI VirtualBox system. Before migration, userspace
multi-user.target took 41.128 s (32.447 s time wait plus 7.202 s pacman-init).
After migration, two boots measured 4.723 s and 4.478 s userspace; the latter
was 6.983 s including the kernel. These are VM observations, not physical-PC
performance guarantees or exact desktop-ready measurements.

Verified signed package installation, persistent keyring after reboot, no failed
systemd units, successful shell load, terminal launch and login-shell guard.
Linux mac80211_hwsim plus NetworkManager provided an isolated virtual AP:
the production NetworkStatus singleton found it with scanning enabled and
disabled scanning after the consumer released it. Test AP/profile removed.

This does not verify the reported physical Wi-Fi adapter. If the panel says
Wi-Fi hardware is missing, PCI/USB IDs, rfkill and driver/firmware logs are still
needed. No claim that missing physical hardware/firmware has been repaired.

Install with the normal StireOS updater (`sudo pacman -Syu`) and reboot after
the transaction and initramfs generation complete. Internet access is needed;
use Ethernet or USB tethering if Wi-Fi is unavailable. Package and repository
signatures remain required. Do not disable signature checks.
